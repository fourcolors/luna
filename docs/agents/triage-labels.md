# Triage labels

Engineering skills use these canonical triage roles. `wontfix` already exists in GitHub; create the remaining canonical labels before the triage workflow first needs them rather than mapping them to semantically different product labels.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an AFK agent |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Will not be actioned |
