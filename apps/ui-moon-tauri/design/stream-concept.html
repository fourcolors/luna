Why this fixes what felt off

Every earlier concept reinvented threads — tabs, popovers, peek panels are all a place per agent. Here there is exactly one place. Delegated work is an updating card inside the conversation, in the spot where it was born. History is just "scroll up" — the stream is the log.

The ontology, respected

  • Ephemeral agents / delegated tasks — visitors: star in the sky + live card in the stream; both die when it's done
  • Cron rhythms — heartbeat lines that coalesce in place ("wake-reasoner · 14 checks · all quiet"), and provenance chips when a scheduled run speaks ("daily-brief · 07:00")
  • Persistent agents — residents: never in the sky while idle; managed in the observatory with status + toggles

One rule for attention

Gold is the only escalation: a gold message in the stream, a gold star in the sky, a gold pip on the moon — three views of the same single question, answered once, anywhere. Everything else is allowed to be quiet.
