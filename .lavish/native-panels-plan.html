Every panel — orb, chat, each settings panel, each artifact — is already a real, separate Tauri WebviewWindow (a genuine OS window). One OS window per card. So this was never "fake windows vs real windows." Only two things are painted in software on top of those real windows:

Root cause #1 — the transparent strip

verified in code

It's an inset asymmetry, not the title bar. The card has a 22px transparent buffer on the sides & bottom, but only 4px on top (trimmed so the header rides up to the native traffic lights). Every side absorbs sub-pixel rounding drift in its buffer — except the top, where a 1–2px drift is fully exposed as a see-through sliver.

Cause → effect chain

  • Snap math runs in card-face space, then subtracts each side's inset to get the OS-window position deck-snap.js:33–36, 107, 346
  • Rounding drifts 1–2px Math.round deck-snap.js:71 · logical↔physical main.rs:2139
  • 22px side buffer hides it; 4px top buffer can't → transparent strip + apparent "shift up"
⚠️

"Always show the top bar" is a red herring for the strip

We ruled out the intuitive culprits in code: hover-reveal never changes layout height (moon-native-titlebar.js:87–105), and the old weld margin-collapse is already gone (moon-dock.js:90–116 only squares corners now). The real fix is one line: symmetrize the top inset — set --card-inset-top: 22px. The native traffic lights follow the header down automatically (their position-sync reads #title-bar's real rect). Pinning the top bar always-on is still worth doing — but as a stability bonus (kills a secondary AppKit re-layout flicker), not the cure.

The one honest tradeoff

🎚

During a multi-window cluster drag, the welded children stay put and snap into formation when you drop — instead of towing live under the cursor. That's exactly the "snap-on-release" feel you said you're fine with, just applied to the whole cluster. Single-window drag already feels native today, so the only new feel is cluster-on-release. Resize stays emulated regardless — native resize-drag is a tao no-op on macOS, unavoidable.
